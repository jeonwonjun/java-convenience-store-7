# java-convenience-store-precourse

## 기능 요구 사항
구매자의 할인 혜택과 재고 상황을 고려하여 최종 결제 금액을 계산하고 안내하는 결제 시스템 구현

1. 파일 입출력 로드
- [ ] 상품 목록과 행사 목록 파일 불러오기

2. 입력
- [ ] 구매할 상품과 수량 입력(예: ```[콜라-10],[사이다-3]```)
  - [예외] 구매할 상품이 특수문자 일 경우, 수량이 숫자가 아닐경우
  - [예외] 구매할 상품이 존재하지 않는 경우
  - [예외] 구매 수량이 재고 수량을 초과한 경우(프로모션 제품, 기본 제품 따로 존재해서 둘 다 비교 필요)
  - [예외] 입력 형식이 맞지 않은 경우
- [ ] 추가 구매 여부(Y/N)
  - 프로그램 다시 작동
  - 지난 결과 저장 필요
* 정확한 예외 발생, "[ERROR] ", 오류 발생 후 ``그 부분부터 다시 입력```

3. 재고 관리
- [ ] 각 상품의 재고 수량을 고려하여 결제 가능 여부 판단
- [ ] 결제된 수량만큼 해당 상품의 재고에서 차감하여 수량 관리
- [ ] 최신 재고 상태 유지 필요

4. 프로모션 & 멤버십
- [ ] 프로모션
  - [ ] 프로모션 최소 갯수보다 적은 물건을 가져온 경우 안내
    - 증정 받을 수 있는 상품 추가
  - [ ] 프로모션 재고가 부족하여 프로모션 혜택 없이 결제해야하는 경우 안내
    - 일부 수량에 대해 정가로 결제
    - [예외] 기간 내에 포함된 경우만 적용
    - 동일 상품에 여러 프로모션 적용 X
    - 프로모션 혜택은 프로모션 재고 내에서만 가능
    - 프로모션 기간 중이라면 프로모션 재고 우선, 부족할 경우 일반 재고 사용
- [ ] 멤버십 할인 적용 여부
  - 멤버십 회원은 프로모션이 아닌 물건 금액의 30% 할인
  - 프로모션 적용 후 남은 금액에 대해 멤버십 할인
  - 최대 한도는 8,000원
     
5. 영수증 출력
  - [ ] 현재 재고 출력
  - [ ] 프로모션 여부 출력
  - [ ] 멤버십 할인 여부 출력
  - [ ] 구매 상품 내역, 증정 상품 내역, 금액 정보 출력
  - [ ] 추가 구매 여부 출력
